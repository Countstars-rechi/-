## 技术栈

| 层次 | 技术 |
|------|------|
| 后端 | Spring Boot 2.7 + Spring Security 5 + JPA/Hibernate |
| 数据库 | MySQL 8.0 |
| 前端 | Thymeleaf + Bootstrap 5 + ECharts 5 |
| 部署 | Docker Compose + 阿里云 ECS |
| JDK | Java 17 |

---

## 功能

- 三角色权限隔离（Customer / Sales / Admin），URL 级别 + 导航栏级别双重隔离
- 未登录可浏览商品，登录后按角色跳转不同首页
- 商品搜索 + 分类筛选 + 分页
- 购物车 → 收货信息 → 下单 → 支付（模拟）→ 订单管理
- 库存自动扣减/取消订单恢复
- 销售人员：商品 CRUD、分类管理、订单状态流转（发货/完成）、浏览日志、销售统计
- 管理员：销售员管理（增删改查/启用禁用/密码重置）、操作日志、用户画像分析
- 基于用户的协同过滤推荐（UserCF），冷启动回退到物品推荐
- ECharts 数据可视化：销售趋势折线图、排行榜柱状图、类别占比
- 用户个人中心（编辑资料、修改密码）
- CSRF 防护，订单/购物车所有权校验
- 邮箱通知（支持模拟模式）

## 本地运行

```bash

./mvnw spring-boot:run          # 启动应用
```

## 部署

```bash
git pull

```
